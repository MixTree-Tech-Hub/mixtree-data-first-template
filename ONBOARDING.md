# Welcome to Data First Series

## What You Need
* GitHub account
* Git installed
* Basic command-line knowledge

## How to Start
1. Click Use this template
2. Name repo mixtree-data-first
3. Clone to your computer
4. Start Week 1 assignments

## Rules

* Follow folder structure
* Commit regularly
* Do not delete graded work
* No datasets larger than 100MB
* Every assignment must have at least one meaningful commit
* Commits must describe what changed and why
